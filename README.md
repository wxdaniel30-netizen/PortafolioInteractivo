
# Portafolio Interactivo

## Descripción
Este proyecto consiste en una página web responsiva desarrollada con HTML, CSS y Bootstrap 5. Su objetivo es presentar proyectos personales mediante un diseño moderno e interactivo.

## Tecnologías utilizadas
- HTML5
- CSS3
- Bootstrap 5
- Visual Studio Code

## Características
- Barra de navegación adaptable a dispositivos móviles.
- Diseño responsivo mediante el sistema Grid de Bootstrap.
- Formulario de contacto con campos para nombre, correo electrónico y mensaje.
- Botones para enviar y limpiar el formulario.

## Transformaciones CSS 2D
Se implementaron tres efectos al pasar el cursor sobre las tarjetas:
- Rotación mediante rotate().
- Escalado mediante scale().
- Traslación y sesgado mediante translateY() y skewX().

Se utilizó la propiedad transition para que los cambios fueran suaves.

## Transformación CSS 3D
Se creó una tarjeta interactiva utilizando perspective, transform-style: preserve-3d, rotateX() y rotateY().

## Animaciones CSS
Se implementaron animaciones con @keyframes:
- aparecer: muestra gradualmente la portada.
- deslizar: desplaza el título al aparecer.
- pulsar: modifica el tamaño y la opacidad de un texto.
- girar: hace rotar continuamente el indicador de carga.

## Diseño responsivo
Se utilizaron las columnas de Bootstrap y media queries para adaptar la página a diferentes tamaños de pantalla.
